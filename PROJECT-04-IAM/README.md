# Project 4 — AWS IAM Access Management

## Objective
To learn how to securely manage users, roles, and permissions in AWS.

## AWS Services Used
- AWS IAM
- IAM Users
- IAM Roles
- IAM Policies

## What I Built
I created an IAM user and an EC2 IAM role with controlled permissions. I also tested permissions to understand how AWS access control works.

## Skills Demonstrated
- IAM user creation
- IAM role creation
- Permission management
- IAM policies
- Least-privilege access

## Result
AWS access was successfully controlled using IAM users, roles, and permissions.
