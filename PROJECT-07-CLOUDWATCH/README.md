# Project 7 — AWS Cloud Monitoring with CloudWatch

## Objective
To learn how to monitor AWS resources and view application logs using Amazon CloudWatch.

## AWS Services Used
- Amazon CloudWatch
- Amazon EC2
- AWS Lambda

## What I Built
I monitored EC2 CPU utilization, viewed Lambda execution logs, and created a CloudWatch alarm for high CPU utilization.

## Skills Demonstrated
- CloudWatch monitoring
- Metrics
- Logs
- Alarms
- EC2 monitoring
- Lambda logging

## Result
AWS resources were successfully monitored using CloudWatch, and an alarm was configured for CPU utilization.

## Monitoring Flow
AWS Resource → CloudWatch Metrics/Logs → Alarm
