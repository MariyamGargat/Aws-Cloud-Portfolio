# Project 6 — Serverless API with AWS Lambda and API Gateway

## Objective
To build a simple serverless API without managing servers.

## AWS Services Used
- AWS Lambda
- Amazon API Gateway
- IAM

## What I Built
I created a Lambda function and connected it to an API Gateway HTTP API. The API invokes the Lambda function and returns a response.

## Skills Demonstrated
- Serverless computing
- Lambda functions
- API Gateway
- HTTP APIs
- IAM permissions

## Architecture
User → API Gateway → Lambda → Response

## Result
The serverless API was successfully deployed and tested through the API endpoint.
