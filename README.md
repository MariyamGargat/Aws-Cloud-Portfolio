# AWS Cloud Portfolio

## About This Portfolio

This repository contains 10 hands-on AWS Cloud projects built to develop practical skills in cloud computing, AWS services, security, networking, databases, serverless architecture, monitoring, and content delivery.

## AWS Skills Demonstrated

- Amazon S3
- Amazon EC2
- Amazon VPC
- AWS IAM
- Amazon RDS
- AWS Lambda
- Amazon API Gateway
- Amazon CloudWatch
- Amazon DynamoDB
- Amazon CloudFront
- AWS Security
- Serverless Architecture
- Cloud Networking
- Monitoring and Logging

## Projects

| # | Project | AWS Services |
|---|---|---|
| 1 | Cloud Storage & Static Website | S3 |
| 2 | Web Server | EC2 |
| 3 | Cloud Network | VPC |
| 4 | Secure Access Management | IAM |
| 5 | Relational Database | RDS |
| 6 | Serverless API | Lambda, API Gateway |
| 7 | Cloud Monitoring | CloudWatch |
| 8 | Serverless NoSQL Application | DynamoDB, Lambda |
| 9 | Global Content Delivery | CloudFront, S3 |
| 10 | Complete Serverless Web Application | S3, CloudFront, API Gateway, Lambda, DynamoDB |

## Final Architecture

User → CloudFront → S3 → API Gateway → Lambda → DynamoDB

Additional AWS services used for security and monitoring include IAM and CloudWatch.
