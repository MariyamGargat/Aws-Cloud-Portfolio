# Project 2 — Amazon EC2 Web Server

## Objective
To learn how to launch and configure a virtual server using Amazon EC2.

## AWS Services Used
- Amazon EC2
- Amazon VPC
- Security Groups

## What I Built
I launched an Amazon EC2 instance using Amazon Linux, configured a security group, connected to the instance, and deployed a simple web server.

## Skills Demonstrated
- EC2 instance creation
- Linux server basics
- Security group configuration
- Public IP access
- Web server deployment

## Result
The web server was successfully launched and accessed through the browser.
